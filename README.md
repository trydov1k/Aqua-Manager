# Aqua Manager - игра, в которой ты играешь за бизнесмена по аквариумным рыбкам
### В ней тебе надо следить за рыбками: кормить их, менять воду в аквариуме
### В игре можно покупать новые виды рыб и новые аквариумы

Игрок начинает с маленького аквариума и нескольких простых рыбок, 
а в финале управляет сетью огромных океанариумов с редкими морскими обитателями, 
экзотическими декорациями.
