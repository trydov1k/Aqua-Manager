# 🐠 Aqua Manager

> Симулятор аквариумного бизнеса на Windows Forms (C#)

---

## 📖 Описание

**Aqua Manager** — это игра-симулятор, в которой вы управляете собственным аквариумным бизнесом.
Покупайте рыбок, давайте им имена, следите за чистотой воды и уровнем голода — и зарабатывайте монеты на процветающем деле.

---

## 🎮 Геймплей

Вы начинаете с одним небольшим аквариумом и парой рыбок. Ваша задача — развивать бизнес:

- **Покупайте рыбок** разных видов — у каждого вида своя цена и доход
- **Кормите питомцев** — голодные рыбки погибают и перестают приносить доход
- **Следите за водой** — загрязнённая вода опасна для рыбок; при сильном загрязнении рыбки стрессуют и начинают голодавть в два раза сильнее, а если чистота упадет до нуля, то все рыбки умрут
- **Расширяйте бизнес** — покупайте новые аквариумы и заполняйте их рыбками
- **Зарабатывайте монеты** — пассивный доход начисляется автоматически каждые 30 секунд

---

## 🕹️ Управление

| Действие | Способ |
|---|---|
| Покормить всех рыбок | Кнопка «Покормить всех» |
| Покормить одну рыбку | Кнопка «Режим кормления» + Клик на рыбку |
| Сменить воду | Кнопка «Сменить воду» |
| Открыть магазин | Кнопка «Магазин» |
| Открыть меню | Кнопка «Меню» или `Escape` |
| Открыть обучение | `F1` или из меню |
| Сменить аквариум | Нажать на название текущего акварима + выбрать нужный|

## 🏪 Магазин

В магазине доступны:

- **Рыбки** — разные виды с разной ценой и пассивным доходом. При покупке можно дать рыбке имя
- **Аквариумы** — расширяют вместимость бизнеса. При покупке можно дать аквариуму имя

---

## 💾 Сохранения

Игра поддерживает **несколько именованных слотов сохранения**. Каждое сохранение хранится отдельным файлом.

Возможности системы сохранений:

- Создавать сохранения с произвольным названием
- Загружать любое из сохранений
- Удалять ненужные слоты

## 🚀 Запуск

### Требования

- Windows 10 / 11
- .NET 10.0

### Сборка из исходников

#### Запуск через .exe файл
- Зайдите на вкладку [Releases](https://github.com/trydov1k/Aqua-Manager/releases)
- Выберите последнюю версию игры (будет пометка Latest)
- Разверните папку Assets
- Скачайте файл AquaManager.exe
- Запустите файл AquaManager.exe

#### Запуск через компилятор (например Visual Studio)
```bash
git clone https://github.com/trydov1k/Aqua-Manager.git
cd Aqua-Manager
dotnet build
dotnet run --project AquaManager
```

## 📁 Структура проекта

```
AquaManager.sln
│
├── AquaManager.Domain (Class Library)
│   ├── Constants/           – статические конфигурационные данные
│   ├── Enums/              – перечисления (типы рыб)
│   ├── Factories/          – фабрики для создания объектов
│   ├── Interfaces/         – контракты для слабой связности
│   ├── Models/             – доменные модели (сущности)
│   ├── Services/           – бизнес-логика (GameEngine, IncomeService, SaveLoadService)
│   └── Properties/         – служебные ресурсы
│
├── AquaManager.Presentation (Windows Forms App)
│   ├── Controls/           – пользовательские контролы (FishControl, ShopItemControl)
│   ├── Enums/              - enum для использования в формах
│   ├── Extensions/         – методы-расширения для удобства
│   ├── Forms/              – UI формы (MainForm, ShopForm, AquariumNameForm)
│   ├── Models/             – вспомогательные модели для UI (SwimmingFish)
│   ├── Resources/          – изображения рыбок и фонов
│   ├── Properties/         – служебные ресурсы
│   └── Program.cs          – точка входа в приложение
│
└── AquaManager.Tests
    ├── DomainTests/        - тесты доменных моделей
    └── PresentationTests/  - тесты моделей из Presentation
```
