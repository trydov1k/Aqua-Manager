# Аналитика проекта: Aqua Manager



## 1. Общее описание игры

**Название:** Aqua Manager (рабочее название)

**Жанр:** Экономический симулятор / Симулятор ухода за аквариумом

**Платформа:** Windows Forms (.NET)

**Целевая аудитория:** Любители симуляторов, казуальных игр, игроки, предпочитающие неторопливый геймплей с элементами менеджмента

**Краткое описание:**

Aqua Manager — это игра, в которой игрок выступает в роли владельца аквариумного бизнеса. Игрок начинает с одного небольшого аквариума и нескольких рыбок. Основная задача — поддерживать здоровье рыбок, своевременно кормить их и следить за чистотой воды. Заработанные деньги можно тратить на покупку новых видов рыб и расширение бизнеса — приобретение дополнительных аквариумов.

## 2. Игровой цикл

### 2.1. Основной цикл игры

```
┌─────────────────────────────────────────────────────────────┐
│                      ИГРОВОЙ ЦИКЛ                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│   │ рыбками  │      │  денег   │      │  бизнеса │          │
```

### 2.2. Временная шкала

- **Игровое время:** привязано к реальному времени через таймер
- **Тик таймера:** 1 секунда
- **Скорость голодания:** зависит от вида рыбы (от 0.2% до 0.67% в секунду)
- **Скорость загрязнения воды:** 0.3% в секунду

## 3. Игровые механики

### 3.1. Кормление рыбок

Игрок может кормить рыбок двумя способами:

| Способ | Описание | Стоимость |
|--------|----------|----------|
| **Кормление всех** | Нажатие кнопки "Покормить всех" — восстанавливает голод всех живых рыбок в текущем аквариуме до 100% | 5 монет × количество живых рыбок |
| **Точечное кормление** | Включение режима кормления, затем клик на конкретную рыбку в списке | 5 монет за одну рыбку |

**Условия:**
- Нельзя кормить мёртвых рыбок
- Если денег недостаточно, операция не выполняется
- После точечного кормления режим можно оставить активным для последующих кормлений

### 3.2. Смена воды

- Нажатие кнопки "Сменить воду" восстанавливает чистоту воды в текущем аквариуме до 100%
- **Стоимость:** 30 монет
- Влияет на всех рыбок в аквариуме

### 3.3. Покупка рыбок

- Открывается форма магазина с доступными видами рыб
- Каждый вид имеет уникальные характеристики:
  - Цена
  - Скорость голодания
- **Условия покупки:**
  - Достаточно денег
  - Есть свободное место в текущем аквариуме

### 3.4. Покупка аквариумов

- Покупка нового аквариума увеличивает количество доступных аквариумов
- **Стоимость:** 500 монет
- Новый аквариум появляется с пустым списком рыбок и 100% чистотой воды

### 3.5. Переключение аквариумов

- Через выпадающий список (ComboBox) игрок выбирает активный аквариум
- При переключении обновляется:
  - Список рыбок
  - Индикатор чистоты воды
- Каждый аквариум сохраняет свои параметры независимо

### 3.6. Удаление мёртвых рыбок

- Кнопка "Убрать мёртвых" удаляет всех рыбок с IsAlive = false
- Освобождает место в аквариуме для новых покупок

### 3.7. Сохранение и загрузка

- Ручное сохранение через кнопку
- Автосохранение при закрытии игры
- Загрузка сохранения при запуске

## 4. Экономическая система

### 4.1. Доходы

| Источник | Механика |
|----------|----------|
| **Пассивный доход** | Каждые 30 секунд игрок получает 5 монет за каждую живую рыбку во всех аквариумах |

### 4.2. Расходы

| Статья расходов | Стоимость |
|-----------------|----------|
| Кормление одной рыбки | 5 монет |
| Смена воды в аквариуме | 30 монет |
| Покупка рыбки (Гуппи) | 40 монет |
| Покупка рыбки (Меченосец) | 70 монет |
| Покупка рыбки (Скалярия) | 100 монет |
| Покупка рыбки (Золотая рыбка) | 150 монет |
| Покупка нового аквариума | 500 монет |

### 4.3. Балансировка

- Начальный капитал игрока: **200 монет**
- Начальный аквариум: 1 штука, вместимость 6 рыбок
- Рыбки начинают приносить доход только после покупки
- Смерть рыбки — потеря вложенных средств

## 5. Механика голода и смерти

### 5.1. Коэффициенты голода (потеря % в секунду)

| Вид рыбки | Скорость голодания | Время до смерти без еды |
|-----------|-------------------|------------------------|
| Гуппи | 0.2% в секунду | ~8 минут 20 секунд |
| Меченосец | 0.33% в секунду | ~5 минут |
| Скалярия | 0.5% в секунду | ~3 минуты 20 секунд |
| Золотая рыбка | 0.67% в секунду | ~2 минуты 30 секунд |

### 5.2. Условия смерти

| Причина | Механика |
|---------|----------|
| **Голод** | Если Hunger ≤ 0, рыбка умирает |
| **Грязная вода** | Если WaterCleanliness ≤ 0, все рыбки в аквариуме умирают |
| **Ускоренное голодание** | Если WaterCleanliness < 20%, рыбки теряют голод в 2 раза быстрее |

### 6.2. Подробное описание моделей

#### 6.2.1. Fish (Рыбка)

**Назначение:** Представляет отдельную рыбку с её параметрами состояния.

| Поле | Тип | Описание | Диапазон |
|------|-----|----------|----------|
| `Name` | string | Имя рыбки | - |
| `Type` | FishType | Тип рыбки | Гуппи |
| `Hunger` | int | Текущий уровень голода | 0–100 |
| `HungerRate` | double | Скорость уменьшения голода (% в секунду) | 0.2–0.67 |
| `Price` | int | Цена покупки рыбки | 40–150 |
| `IsAlive` | bool | Жива ли рыбка | true/false |

**Методы:**
- `Feed()` — восстанавливает голод до 100
- `UpdateHunger()` — уменьшает голод на HungerRate
- `Die()` — устанавливает IsAlive = false, Hunger = 0

---

#### 6.2.2. Aquarium (Аквариум)

**Назначение:** Представляет отдельный аквариум с его содержимым и состоянием.

| Поле | Тип | Описание | Диапазон |
|------|-----|----------|----------|
| `Name` | string | Название аквариума (можно переименовать) | - |
| `WaterCleanliness` | double | Уровень чистоты воды | 0–100 |
| `FishList` | List\<Fish\> | Список рыбок в аквариуме | - |
| `Capacity` | int | Максимальное количество рыбок | 6 |

**Методы:**
- `CleanWater()` — устанавливает WaterCleanliness = 100
- `AddFish(Fish fish)` — добавляет рыбку, если есть место
- `RemoveFish(Fish fish)` — удаляет рыбку
- `RemoveDeadFish()` — удаляет всех мёртвых рыбок
- `GetLiveFishCount()` — возвращает количество живых рыбок

---

#### 6.2.3. Player (Игрок)

**Назначение:** Хранит данные о прогрессе игрока.

| Поле | Тип | Описание |
|------|-----|----------|
| `Money` | int | Количество монет |
| `Aquariums` | List\<Aquarium\> | Список всех аквариумов |
| `CurrentAquariumIndex` | int | Индекс текущего выбранного аквариума |

**Методы:**
- `GetCurrentAquarium()` — возвращает текущий аквариум
- `AddMoney(int amount)` — добавляет деньги
- `SpendMoney(int amount)` — тратит деньги, возвращает успех операции
- `CanAfford(int amount)` — проверяет, хватает ли денег

---

#### 6.2.4. FishType (Перечисление)

**Назначение:** Определяет доступные виды рыб с их фиксированными характеристиками.

| Значение | Name | Price | HungerRate |
|----------|------|-------|------------|
| `Guppy` | "Гуппи" | 40 | 0.2 |
| `Swordtail` | "Меченосец" | 70 | 0.33 |
| `Angelfish` | "Скалярия" | 100 | 0.5 |
| `Goldfish` | "Золотая рыбка" | 150 | 0.67 |

**Методы:**
- `GetFish()` — создаёт новый экземпляр Fish с соответствующими параметрами

---

#### 6.2.5. GameState (Состояние игры)

**Назначение:** Хранит временное состояние игровой сессии.

| Поле | Тип | Описание |
|------|-----|----------|
| `IsFeedingMode` | bool | Активен ли режим точечного кормления |
| `GameTimer` | Timer | Таймер, обновляющий состояние каждую секунду |
| `IncomeTimer` | Timer | Таймер для пассивного дохода (каждые 30 секунд) |

## 7. Сценарии использования (Use Cases)

### 7.1. UC-01: Кормление всех рыбок

| Элемент | Описание |
|---------|----------|
| **Актор** | Игрок |
| **Предусловие** | Есть хотя бы одна живая рыбка в текущем аквариуме |
| **Основной поток** | 1. Игрок нажимает кнопку "Покормить всех"<br>2. Система проверяет наличие денег (5 × количество живых рыбок)<br>3. Если денег достаточно, голод всех живых рыбок восстанавливается до 100%<br>4. Система списывает деньги<br>5. Обновляется интерфейс |
| **Альтернативный поток** | Если денег недостаточно, система показывает сообщение об ошибке |
| **Постусловие** | Все живые рыбки сыты, деньги уменьшены |

Если денег достаточно, голод выбранной рыбки восстанавливается до 100%<br>6. Система списывает 5 монет<br>7. Обновляется интерфейс |

Система проверяет наличие свободного места в текущем аквариуме<br>5. Если условия выполнены, создаётся новая рыбка<br>6. Рыбка добавляется в текущий аквариум<br>7. Деньги списываются<br>8. ## 11. Словарь терминов

| Термин | Определение |
|--------|-------------|
| **Голод (Hunger)** | Параметр рыбки от 0 до 100, отражающий уровень сытости. При 0 рыбка умирает |
| **Чистота воды (WaterCleanliness)** | Параметр аквариума от 0 до 100. Влияет на скорость голодания рыбок |
| **Коэффициент голода (HungerRate)** | Скорость уменьшения голода рыбки в процентах в секунду |
| **Режим кормления** | Состояние интерфейса, при котором клик на рыбку приводит к её кормлению |
| **Тик таймера** | Единица игрового времени, равная 1 реальной секунде |
| **Пассивный доход** | Автоматическое начисление монет за каждую живую рыбку |

## 12. Риски и ограничения

| Риск | Вероятность | Способ mitigation |
|------|-------------|-------------------|
| Потеря сохранения при ошибке JSON | Низкая | Реализовать резервное копирование, валидацию данных |
| Баланс экономики (слишком легко/сложно) | Средняя | Предусмотреть конфигурационный файл с настройками цен |
| Проблемы с производительностью при большом количестве рыбок | Низкая | Оптимизировать обновление интерфейса, не перерисовывать всё при каждом тике |
| Потеря прогресса при аварийном завершении | Средняя | Автосохранение каждые 30 секунд |

## 13. Возможные расширения (Roadmap)

1. **Декорации** — возможность украшать аквариум, влияющее на доход
2. **Размножение рыбок** — появление мальков при хороших условиях
3. **Случайные события** — болезни, приход коллекционеров
4. **Анимация** — плавающие рыбки в PictureBox
5. **Звуки** — кормление, смена воды, покупка
6. **Достижения** — система наград за определённые действия
